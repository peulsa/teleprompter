# Teleprompter

Aplicación web local para leer guiones con desplazamiento automático.

El archivo que inicia la aplicación es:

`C:\...\...\...\teleprompter\index.html`

## Cómo iniciarlo

1. Abre el Explorador de archivos de Windows.
2. Abre la carpeta **teleprompter**.
3. Haz doble clic en `index.html`. Se abrirá en Chrome, Edge o Firefox.
2. Pega el guion.
3. Ajusta las palabras por minuto, tamaño, ancho y colores.
4. Pulsa **Iniciar** o la barra espaciadora.
5. Usa **Abrir ventana flotante** para tener una ventana estrecha y redimensionable.

No necesitas ejecutar `npm install` ni `php artisan serve`.

## Modo compacto

- Para entrar, pulsa **Modo compacto**.
- Para volver, pulsa **Salir del modo compacto**, que queda visible en la esquina superior derecha.
- También puedes presionar `Esc` para regresar a la vista completa.

## Atajos

- `Espacio`: iniciar o pausar.
- `R`: reiniciar.
- `↑` / `↓`: subir o bajar la velocidad.
- `F`: pantalla completa.
- `Esc`: salir del modo compacto o de pantalla completa.

Los ajustes y el texto se guardan automáticamente en el navegador.
